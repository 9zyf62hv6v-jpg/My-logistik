# Дашборд «Моя Логистика»

Веб-приложение для управления процессами пивоваренного завода. Система позволяет вести учет клиентов, заказов, водителей, маршрутов и возвратной тары (кег).

## 🛠 Стек технологий
*   Python (Flask)
*   SQLite (База данных)
*   HTML/CSS/JS (интерфейс)
*   API Яндекс.Карт (для геокодинга, если используется в `geocode.py`)

## 🚀 Как запустить проект локально
1. Клонируйте репозиторий: `git clone https://github.com/9zyf62hv6v-jpg/---_---------.git`
2. Установите зависимости: `pip install -r requirements.txt` *(см. пункт 2 ниже)*
3. Запустите приложение: `python app.py`
4. Откройте в браузере: `http://127.0.0.1:5000`

📥 Импорт из Excel

Загрузите файл с клиентами — система создаст заказы и добавит новых клиентов

📋 Как это работает

  1. Загружаете файл .xls или .xlsx с колонками:
    • A: Имя клиента
    • B: Адрес
    • C: Сумма заказа
  2. Система проверяет каждого клиента:
    • Есть в базе? → использует существующего
    • Нет? → создаёт нового
  3. Создаёт заказ на каждого клиента с суммой из файла
  4. Проверяет дубли: если такой же заказ (клиент + сумма + дата) уже есть — пропускает
  5. Показывает отчёт: сколько клиентов, заказов, пропущено дублей

⚠️ Важно знать
